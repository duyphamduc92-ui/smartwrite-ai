# SmartWrite AI

SmartWrite AI is a simple AI-powered web application that improves user-written text based on a selected writing style.

## Features

- Improve text using AI
- Professional, Friendly, or Shorter styles
- Simple web interface
- Automated tests with pytest
- GitHub Actions CI

## Tech Stack

- Python
- Flask
- OpenAI API
- HTML/CSS
- pytest
- GitHub Actions

## Architecture

```text
User → Flask Web App → OpenAI API → Improved Text
